# Tilemap Tools

Outils en ligne de commande pour créer et manipuler des tilemaps.

## Installation

Pour fonctionner ce module à besoin du module pyxel:

```bash
pip install pyxel
```

Ensuite vous pourrez executer cette commande:

```bash
pip install -e .
```

## Utilisation

### Créer un modèle
```bash
tilemap create 9 -o map
tilemap create 16 -o map
```
